# AlertMonitor (АЛЕРТОН) 🚨

Приложение для мониторинга воздушных угроз, ракетной опасности и активности БПЛА в режиме реального времени.

## Основные возможности

- 📡 **Сбор данных:** Автоматический сбор информации из официальных каналов МЧС и проверенных Telegram-источников.
- 🧠 **Локальный анализ:** Обработка текстов сообщений непосредственно на устройстве для мгновенного определения типа угрозы (ракета, БПЛА, артобстрел).
- 🔔 **Умные уведомления:** 
    - Громкие оповещения для критических угроз (даже в ночном режиме, если настроено).
    - Разные звуковые сигналы для ракетной опасности и БПЛА.
    - Уведомления об угрозах в соседних регионах ("Угроза рядом").
- 🗺️ **Карта:** Визуальное отображение статуса регионов.
- 📜 **История:** Просмотр последних событий и архива оповещений.
- ⚙️ **Гибкие настройки:** Выбор домашнего региона, настройка чувствительности, источников данных и ночного режима.

## Установка и использование

1. Скачайте APK файл (в разделе Releases).
2. При первом запуске предоставьте необходимые разрешения:
    - **Уведомления:** Для получения оперативных сводок.
    - **Поверх других окон:** Для отображения полноэкранного окна тревоги при критической угрозе.
    - **Игнорирование оптимизации батареи:** Чтобы фоновая служба мониторинга не останавливалась системой.
3. Выберите свой регион в настройках для получения персонализированных уведомлений.

## Технологии

- **Kotlin & Jetpack Compose:** Современный интерфейс и быстрая работа.
- **Room:** Локальное хранение истории событий.
- **DataStore:** Сохранение настроек пользователя.
- **Coroutines & Flow:** Эффективная фоновая обработка данных.
